Implemented scope
-----------------
- Opening any remote message immediately writes the local read state before navigation and then
  commits IMAP \Seen on the serialized account lane. The list keeps an optimistic read overlay so
  a delayed Room/IMAP snapshot cannot make the row look unread again while returning from detail.
- Added an Unread mailbox between Inbox and Starred for single-account and all-account views.
- Sent now combines real provider Sent-folder mail with local queued/sending/failed placeholders.
  SMTP delivery and Sent-folder reconciliation are separated by a stable Message-ID so a retry of
  IMAP reconciliation cannot resend the message.
- Drafts combines provider Drafts-folder mail with local drafts. Exiting a meaningful composer
  opens a Save / Discard / Cancel decision. Saved drafts are queued to an IMAP APPEND worker and
  safely replace a previous server draft only after the new copy is accepted.
- Sent and Drafts folder resolution supports IMAP special-use attributes, common aliases, Gmail,
  Outlook/Microsoft 365, NetEase and general fallback names.
- Detail forward/back transitions are opaque, shorter Telegram-like horizontal movements. The
  Android predictive-back opt-in remains enabled and Navigation Compose owns the back gesture.
- Detail HTML reveal uses a small one-time alpha/scale reveal over the stable skeleton to hide the
  remaining WebView first-frame flash without drawing a second real text layer.
- Existing OAuth/XOAUTH2, app-password replacement, K-9-style incremental inbox sync, body
  prefetch, FLUID/DESKTOP HTML modes and Cloudflare/GitHub/NetEase/Bybit fixes remain intact.
