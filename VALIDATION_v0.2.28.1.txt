Hotfix scope
------------
This hotfix resolves the Android Compose compiler failure reported at DetailScreen.kt:203:

  @Composable invocations can only happen from the context of a @Composable function

Root cause:
- tr("no_subject") is a @Composable localization function;
- v0.2.28.0 invoked it inside the calculation lambda passed to remember { ... };
- remember's calculation lambda is not a composable context.

Fix:
- resolve noSubjectLabel = tr("no_subject") in the surrounding composable scope;
- add noSubjectLabel to the remember key list;
- use the resulting ordinary String inside the non-composable remember calculation.

This preserves language-change correctness and does not change the v0.2.28.0 detail layout,
body scheduling, WebView reuse, Header/Body separation, HTML dual layout, OAuth or bottom dock.
