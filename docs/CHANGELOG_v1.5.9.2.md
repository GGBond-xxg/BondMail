# BondMail v1.5.9.2

- 新增「设置 → 外观 → Liquid Glass 调节」：模糊半径、折射高度、折射强度和色散四个滑杆，实时预览、自动保存、恢复默认；参数应用于整套玻璃控件。
- 邮件内翻译语言、翻译服务下拉菜单和翻译进度使用 Liquid Glass 样式。
- 收紧邮件顶部布局，为账户名称保留更多空间；统一首页搜索、写邮件附件与发送按钮的视觉尺寸。
- 补齐翻译服务、AI 配置、回复技能和邮件工具中的玻璃菜单及操作按钮，AI 表单使用无描边圆角输入框。
- 修正样式及浅深色切换后翻译进度和邮件底栏残留浅色背景的问题。
- 保留 1.5.9.1 的 WebView 硬件图层兼容处理及底栏手势修复。

Material 3、MIUIX 和 Liquid Glass 保持为三个独立界面样式。

验证：87 项单元测试通过；Debug lint 与优化包检查通过。vivo 实机覆盖邮件菜单、浅深色、翻译进度对比度、写信操作、AI 配置编辑、开关及底栏拖动；Mobile MCP 检查调节预览、参数保存和主要设置弹窗。
