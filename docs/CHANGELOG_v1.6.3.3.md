# v1.6.3.3

- M3 底部导航改为左右独立绘制的拼接药丸：高度 52dp、间隙 2dp、外侧圆角 26dp，连接处默认 4dp。
- 按压仅改变对应部件的连接圆角（4dp → 8dp），按下 140ms、松开或取消 260ms 恢复；移除额外按压高亮、水波纹和按压阴影。
- 保留导航选中背景及约 300ms 平滑移动；背景和图标使用 M3 主题色，适配莫奈、浅深色及关闭系统动效。
- 主导航和邮件详情继续共用底栏，原有功能保持不变；Glass、MIUIX 样式保持原样。
- 更新底栏规范，便于其他项目统一样式。

验证：M3 拼接底栏真机交互测试、三主题主导航/邮件详情共用底栏回归测试均通过，覆盖快速点击、长按取消、导航切换、右侧操作和关闭动效。
