# BondMail v0.2.29.1

## 邮件详情首帧稳定热修复

### 详情转场不再叠加两层文字

真机录屏显示，“粗 → 细”并不是邮件字体本身在加载中变化，而是进入详情时整页执行透明度渐变：详情主题、发件人文字与底下仍可见的邮件列表短暂叠在一起，视觉上像先变粗再恢复。

本版将列表进入邮件详情的动画改为：

- 详情页从第一帧开始保持完全不透明；
- 只保留轻量水平位移，不再做整页淡入；
- 返回列表同样只做位移，不再通过淡出露出底层页面；
- 顶栏、邮件正文和底部 Dock 的内部动画不受影响。

### 已打开邮件立即复用

此前即使 HTML 清理结果和最后一封邮件的 WebView 页面都在内存中，重新进入详情时仍会先把 `prepared` 清空，再经过后台调度取回缓存，因此会短暂显示加载占位。

本版增加：

- HTML LRU 同步内存命中；
- 进入详情首帧检查单实例 WebView 中保留的已提交页面；
- 同一封邮件可在首帧直接挂载已栅格化页面；
- 缓存命中时不再重新进入加载占位状态；
- 屏幕宽度、主题颜色、远程图片状态变化时仍会正确生成新页面。

### 加载占位与最终字体统一

- Gmail 风格主题在 Compose 占位和 WebView 中统一使用 Android `sans-serif`；
- 邮件主题统一为 Gmail 更接近的常规字重；
- 移除生成标题区域禁用字体合成的设置，避免 WebView 把 500/600 字重回退成更细的 400；
- HTML 准备缓存升级为 `layout-v24`，旧版字体规则自动失效。
