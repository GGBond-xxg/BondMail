# BondMail v1.6.1.7

- Glass 文字按钮按内容自动增高，保留上下留白并居中对齐；禁用状态采用相同布局，避免英文或大字体换行后贴边。
- 写信的签名、回复模板，以及添加邮箱选项和通知授权操作，在空间不足时自动纵向排列。
- 发送主题与撤回发送按钮分行显示，长主题最多显示两行并以省略号结尾，避免挤压撤回操作。
- 调整正文显示设置中的重置按钮间距，并补齐设置选项、翻译选项和模板预览的长文本省略处理。
- 修复航旅行程单等固定宽度邮件被错误识别为手机布局的问题：小 Logo 不再作为整封邮件内容宽度的依据，保留原始表格比例并整体缩放，避免票号和右侧栏目被挤成竖排。

版本：`versionCode 199`，`versionName 1.6.1.7`。沿用已有签名，支持覆盖安装，保留邮箱数据。

验证：103 项单元测试、8 项真机邮件排版回归及 1 项长文字布局测试通过；长文字测试覆盖 300dp 宽度、正常及 1.6 倍字体、浅色及深色界面。小米原始行程单已实机确认票号及航班表格恢复完整显示。优化 APK 构建和 release lint vital 检查通过。
