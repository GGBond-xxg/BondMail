# BondMail v1.5.9

基于 v1.5.8.1 重建 Liquid Glass，替换早期预览实现。

- 新增完整独立的 Liquid Glass 界面样式，保留原有 Material 3 和 MIUIX。
- 使用 Kyant Backdrop 1.0.6 和官方 Catalog 控件示例。
- 统一导航、按钮、可拖动开关、图标、选择菜单、确认弹窗、输入框的样式。
- 补齐邮件详情与写信页的玻璃操作控件，包括回复、转发、分享、删除、翻译和发送。
- 删除界面样式下的介绍文字。
- 支持浅深色，并保留低版本 Android 和系统辅助设置下的效果回退。

版本名称 1.5.9，内部版本号 180，可覆盖安装早期测试包。
