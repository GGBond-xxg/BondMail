# BondMail v1.5.9 — Liquid Glass 预览版

- 设置 → 外观 → 界面样式新增 Liquid Glass，随时可切回 Material 3 或 MIUIX。
- 底部导航、写信按钮与收件箱顶栏使用实时背景模糊、折射及边缘高光。
- 保留邮件与设置内容的清晰材质，支持浅色、深色、跟随系统和动态/自定义主题色。
- Android 13+ 启用完整效果；较早系统、省电、高对比度文字或减少动画时回退。
- 保留用户语言、账户、邮件与现有偏好；样式选择在重启后恢复。
- 接入适合 Compose 的 Kyant0/AndroidLiquidGlass 固定源码，来源与修改见第三方声明。

调试构建、Android Lint、86 项单元测试及 Android 15 真机样式回归已通过。
真机回归包含实际选择器、浅/深/动态色、Activity 重建、减少动画及三种样式往返切换。
预览版用于继续收集不同 Android 版本与 GPU 的表现；旧系统回退尚未在旧系统真机验证。
