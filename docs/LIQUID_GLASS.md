# Liquid Glass

在 **设置 → 外观 → 界面样式 → Liquid Glass** 选择。Material 3 和 MIUIX 保持独立，
可以随时切回；界面内不显示介绍文字。支持浅色、深色和跟随系统。

## 视觉与交互

这是一套独立界面样式，采用中性分组背景、蓝色操作色、单独的字阶与圆角：

- 底部导航使用官方 LiquidBottomTabs 示例的可拖动玻璃选中块与按压形变。
- 按钮和圆形操作使用 LiquidButton；写信、发送、回复、转发、分享、删除、翻译均接入。
- 开关使用 LiquidToggle 的玻璃滑块、拖动和弹性反馈，并补充无障碍语义及禁用状态。
- 菜单和确认弹窗使用背景采样、折射边缘及较强磨砂，输入框使用无描边圆角样式。
- 常用邮件操作采用 BondMail 自制的圆角线性图标；正文、列表和邮件品牌标识保持清晰。

当前应用没有滑杆设置，因此没有为了展示效果新增无关控件。

Android 13+ 使用完整光学效果。旧 Android、省电模式、高对比度文字或移除动画
开启时保留主题配色和控件布局，降低效果并使用实色材质。

## 来源与架构

本次以 **v1.5.8.1 / 13366993474d23d28fc121c31836b29c548e010b** 的应用代码为基线重建
v1.5.9。使用 Kyant0/AndroidLiquidGlass 稳定版 **Backdrop 1.0.6** 的源码和 Catalog 示例，
替换早期预览版的 alpha04 渲染器。源码固定在
`896a94a3ade1cc1a940b92365f942a34971fecda`；许可与适配列表见 `THIRD_PARTY_NOTICES.md`。
保留现有 Kotlin/Compose 工具链和最低 Android 版本。

`LiquidGlassTheme.kt` 定义配色、材质、回退与背景源；`LiquidGlassComponents.kt` 实现
应用控件适配；`ui/glass` 保存官方示例的适配实现。各页面内容层与浮动控件分开录制，
弹窗只读取主窗口的独立背景源，避免同一个 RenderNode 采样自身。

本次直接提交到 main，不创建新分支，也不改写已推送的历史。
