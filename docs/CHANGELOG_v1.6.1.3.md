# BondMail v1.6.1.3

- 新增 Toobit、BloFin、Tapbit、XT.COM、eBay 专属发件人图标。四家交易所使用官网或官方品牌素材库的矢量标志。
- 新增 201 个独立图标，并完善 Dropbox、Figma、Notion、Shopee、Stripe、Wise、Zoom 等 7 个已有品牌。内置图标总数增至 480 个（含通用分类图标）。
- 本批 208 个品牌覆盖交易所、金融支付、电商零售、办公设计、AI、开发云服务、社交、影音票务、教育科研、餐饮、旅游航空、物流、健康运动、企业服务、招聘、硬件及工业等 17 类，配置 261 个域名。
- 专属域名优先于通用分类，支持子域名并优先识别具体产品；新增名称别名只匹配完整显示名称，避免 XT 误匹配 Next/Text 等单词。邮件主题不参与这些品牌的识别。
- 清理影响单色主题的底板，保留轮廓和镂空，使图标适配浅色、深色及应用主题着色。资源随 APK 离线内置。

版本：`versionCode 195`，`versionName 1.6.1.3`。沿用已有签名，支持覆盖安装。

验证：103 项单元测试通过；vivo V2310 / Android 15 上 3 项图标仪器测试通过，覆盖本批 208 个品牌的真实矢量渲染、域名别名、名称回退及已有图标回归；明暗主题预览已人工检查。优化 APK 构建与 release lint vital 检查通过。

完整品牌清单见 [图标目录](ICON_CATALOG_v1.6.1.3.md)。本批覆盖常见品牌，后续可通过统一图标目录持续补充。
