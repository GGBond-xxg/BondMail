# BondMail v0.2.19.0

本版针对 v0.2.18.0 真机截图与录屏继续处理邮件正文首帧白闪、下拉刷新反馈消失、首页顶栏按钮风格不统一、Yahoo 等多域名菜单挤压表单、页面背景层级不一致，以及部分 HTML 邮件内容被裁切、过度缩窄或向右偏移的问题。

## 1. 邮件正文首帧改为同色占位与渐显

- WebView 创建和文档加载期间不再直接暴露系统默认白色画布。
- 详情页会立即绘制与当前主题背景一致的正文占位层，并复用真实发件人头像、名称、地址和收件账户信息。
- 只有正文等待超过短暂阈值时才显示细线加载进度，缓存命中时不会闪一下加载器。
- `onPageCommitVisible` / `onPageFinished` 确认正文可见后，WebView 使用强调减速曲线短暂渐显；占位层按相反 alpha 同步退出。
- WebView 本身仍不参加页面尺寸、共享边界或缩放动画，避免重新引入 Chromium 首帧卡顿。

## 2. 首页下拉刷新反馈恢复

- 下拉拖动继续使用跟手的圆形进度指示器，达到阈值时保留一次触觉反馈。
- 松手后列表通过高阻尼弹簧回到原位，不保留会挤压邮件列表的固定刷新区域。
- 同步进行中在不透明顶栏底部显示 3dp 线性进度条，恢复“正在同步”的持续反馈。
- 顶部进度条以 Overlay 形式绘制，不改变顶栏高度、文件夹栏位置或邮件列表测量结果。
- 拖动圆形指示器只属于手势阶段，列表归位后由顶栏进度条接管，避免两个指示器重叠。

## 3. 首页顶栏按钮统一

- 左上抽屉、搜索、更多和添加邮箱均使用 44dp 圆形容器。
- 四个入口统一使用 `surfaceContainerHigh`、相同图标尺寸、相同 0.90 按压缩放和 Material ripple。
- 搜索收起状态与其他按钮拥有相同视觉层级；展开时仍由同一个 Surface 执行 Container Transform。
- 搜索按钮跟随整个顶栏一起从屏幕边界收回/返回，展开和关闭期间仍只绘制一个搜索图标。
- 邮件详情返回/星标/更多、写信返回/附件/发送及行内编辑等次级操作继续使用标准 IconButton 点击热区，不到处增加永久圆底，保持层级区分。

## 4. 多域名选择改为悬浮菜单

- Yahoo 等服务商的后缀菜单改为真正的 `DropdownMenu` Popup，不再参与表单布局，也不会把显示名称和授权码输入框顶下去。
- 域名字段根据屏幕宽度在 152–210dp 范围内计算，用户名字段占据剩余空间。
- 菜单宽度至少与域名字段一致、最大 240dp，完整显示 `@yahoo.com`、`@yahoo.co.uk` 等后缀。
- 当前选中项保留勾选样式、圆角、边框和阴影，点击后菜单立即关闭。

## 5. 页面背景与主题层级统一

- 首页、联系人、设置、写信 Bottom Sheet、添加邮箱和邮件详情的根背景统一使用 `colorScheme.background`。
- 首页和详情顶栏统一使用 `surfaceContainerLow`，列表/联系人卡片使用 `surfaceContainerLowest`，浮层与操作 Dock 使用更高 Surface 角色。
- 侧边抽屉与主页面共享同一根背景，打开后不再像进入另一套页面。
- 非动态取色模式补充一致的浅色/深色 Surface 层级；动态取色模式继续使用系统 Material 配色，但页面也遵循相同角色分工。

## 6. HTML 邮件宽度和水平偏移修复

邮件文档布局缓存升级为 `layout-v9`，旧的错误适配结果不会继续复用。

- 为邮件原始根节点增加专用 class，清除根层固定 `left/right`、float、translate 和异常宽度。
- 顶层表格及常见包装表格限制为 100% 视口宽度。
- 所有表格单元格增加 `min-width:0` / `max-width:100%`，长标题和正文允许自然换行。
- 引用邮件、Gmail Quote 和 Yahoo Quote 的左边距归零，仅保留 8px 轻量引用缩进。
- 对明显来自桌面模板的 48px 以上左右 margin/padding 做保守上限处理，避免手机上只剩很窄的文字列。
- 图片、视频和 SVG 继续限制在可用宽度内；不强制修改没有 `viewBox` 的小型 SVG 高度，避免邮件 ICON 消失。
- HTML/body 强制使用当前 App 背景，内部品牌卡片仍可保留发件人自己的背景色。

## 7. 详情顶栏收回后的空白条修复

- HTML 顶部安全区与详情顶栏统一为 88dp 视觉高度。
- WebView 的滚动回调返回的是设备物理像素，本版会按屏幕 density 把 88dp/72dp 阈值转换为真实像素，再决定收起或恢复顶栏。
- 高密度手机上不再只滚动二三十 dp 就提前隐藏顶栏，从而避免顶部安全区尚未被消耗时露出一块空白。
- 顶栏、发件人头部和正文背景使用相邻 Surface 角色，滚动衔接不再出现明显色块断层。
