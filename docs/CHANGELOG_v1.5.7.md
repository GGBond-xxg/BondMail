# BondMail v1.5.7

版本代码：165。可覆盖安装 v1.5.6.2，保留现有应用数据。

本版汇总近期同版本补丁，正式递增版本号：

- AI 模型列表隐藏已知向量、重排序、生图和语音模型，对话候选优先，未知能力标注“待验证”，保留手动输入。
- 新增可选回复技能，支持本地 Markdown / 文本与 HTTPS 链接导入、预览编辑、加密保存、停用及删除，仅用于生成回复。
- 关于 → 更多新增 AI 使用免责声明和感谢声明，README 同步说明。
- 新增 Meta 品牌图标，保留 Facebook、Instagram 等专属图标及已有手动分类。

模型筛选与回复技能等功能已有 76 项 JVM 回归测试通过；本版尚未进行真机复测。

同版本界面优化：回复技能改为独立管理页，复用 Material 3 / MIUIX 顶栏与卡片；点击卡片选择技能，更多菜单编辑/删除，文件与链接导入分开，独立编辑页固定保存按钮。已检查三语文案，本次界面尚未真机复测。
