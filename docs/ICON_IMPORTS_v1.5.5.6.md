# 用户提供的 SVG

本批来源为用户提供的本地 SVG；品牌标识权利归各权利人，未推断或另行授予许可。
Clothes.svg、Sports.svg 原始注释标明来自 SVG Repo（https://www.svgrepo.com/）；其余来源未进一步推断。
原始文件留在本地 ICON 目录，运行时使用 contact_logos 根目录中整理过的单色版本。
文件对应关系见 tools/icon-sync/catalog.json 的 local 字段。根目录资源优先，同步不会覆盖手工修复。

处理：展开 CSS 和继承填充规则，删除透明占位矩形及 ASICS、ERKE、PEAK 的白色底板；ASICS 白色内孔合并为 evenodd 镂空。保留原始几何与变换。

ASUS、Antgroup 已有资源，继续复用。CE 为认证标志，不参与邮件匹配。乔丹.svg 是 Air Jordan 飞人标志，与用户要求的中国乔丹／中乔体育不同，暂不打包；该品牌名称使用 Sports 通用图标。

分类匹配只检查发件人名称，不使用邮件主题／正文推测服饰或运动类别。域名只按完整域名或子域名匹配。图标不代表发件人经过身份认证。
