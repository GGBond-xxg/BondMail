# BondMail v0.2.22.0

本版根据首页刷新截图、`邮件内容下滑卡顿.mp4`、`长按对比.mp4`、写邮件展开截图、添加邮箱输入截图，以及新账户首次同步/切后台复现步骤继续调整。重点是收敛刷新反馈、统一长按 Shape、缩小 Gmail 分组圆角、改善 HTML 邮件触摸与手机宽度、修复前后台切换留下的加载状态和误报，并完成写信 Sheet、未读层级、邮箱后缀输入与详情头部间距。

## 1. 下拉刷新只保留顶部线性进度条

旧实现同时存在手势圆圈与顶栏进度线，深色模式下尤其容易看到两套加载反馈。本版：

- 保留列表跟手下移、阻尼、80dp 触发阈值和越过阈值的触觉反馈；
- 手指拖动阶段不再绘制圆圈、圆弧或旋转图标；
- 未达到阈值时松手只执行弹簧归位；
- 超过阈值松手后开始同步，列表同时归位；
- 同步期间只显示顶栏底部原有的 3dp `LinearProgressIndicator`；
- App 进入后台时立即清除可见刷新状态，不会在返回后残留永久加载动画。

## 2. Gmail 12dp / 5dp 分组圆角与选中形变

`MailContentDefaults` 的外圆角由 24dp 调整为 12dp，内部相邻圆角保持 5dp：

- 单独一项：四角 12dp；
- 第一项：顶部两角 12dp，底部两角 5dp；
- 中间项：四角 5dp；
- 最后一项：顶部两角 5dp，底部两角 12dp。

邮件进入选择状态时，不论位于首项、中间项还是末项，四个角都会从当前几何状态动画过渡为 12dp；取消选择后再动画恢复到所在位置的 12dp / 5dp Shape。列表间距和测量高度不变，因此形变不会推动相邻邮件。

## 3. 邮件与联系人共用按压、阴影和裁切组件

新增 `GroupedListSurface`，邮件、联系人和搜索结果不再分别维护 Card/Surface 长按实现：

- 外层 `Surface` 使用当前 Shape 绘制阴影；
- 内层点击区域先按同一个 Shape 裁切，再绘制 ripple；
- 普通点击、长按、选中与联系人按压使用同一套轻量 elevation 和按压缩放；
- 邮件圆角形变过程中，阴影、ripple 与内容裁切同步变化；
- 不再出现方形阴影或方形按压蒙层；
- 邮件左右滑动背景继续复用该条目的分组 Shape，选择模式下禁用滑动。

## 4. 未读邮件与右侧信息层级

深色动态主题下仅依靠粗体不够明显。本版增加多层但克制的未读提示：

- `BondMailSurfacePalette.contentUnread` 使用动态主色容器与内容 Surface 混合；
- 未读邮件左侧显示 3dp 主色强调条；
- 发件人、主题继续使用粗体/半粗体；
- 时间使用主色，并在时间左侧显示 5dp 主色圆点；
- 预览文字仍保持次级层级，避免整行过重。

每封邮件右侧区域固定为 52dp，时间与星标都靠最右侧对齐，不再因时间字符串长度不同左右漂移。

## 5. 首页顶栏操作顺序与返回层级

顶栏右侧顺序调整为：

```text
搜索 → 添加邮箱 → 更多
```

三个按钮仍处于同一个真实顶栏 Row，共用同一个 `translationY`、时长与缓动。联系人和设置属于邮件首页的次级 Tab：

- 联系人/设置按系统返回，先回邮件首页；
- 邮件首页再次按返回，才交由 Activity 退出；
- 抽屉打开时仍优先关闭抽屉，不会同时切换 Tab。

## 6. 邮件正文滚动与手机宽度适配

详情 WebView 改为持有一次完整纵向触摸序列，避免 Compose 父层在短距离拖动时中途抢走手势：

- `ACTION_DOWN` 到 `ACTION_UP/CANCEL` 期间由 WebView 保持触摸所有权；
- 关闭 WebView 的嵌套滚动交接；
- 保留 Android WebView 顶部/底部过滚反馈；
- WebView 回收到单实例池时清除触摸与滚动监听，下一封邮件不会继承旧回调。

HTML 文档缓存升级为 `layout-v15`：

- viewport 按手机宽度布局并允许正常双指缩放；
- WebView 开启 overview 与文字自动适配；
- 320px 以上固定 `width`、`min-width`、`max-width` 归一化到视口；
- 宽布局中的嵌套 `table/tbody/tr` 继续限制到可用宽度；
- 长链接、段落、`span`、表格单元格和引用块允许断行；
- 图片、视频与根内容后代不再超出屏幕；
- 针对 GitHub、Cloudflare 和桌面 newsletter 的右侧裁切增加更深层宽度约束。

## 7. 写邮件 Bottom Sheet 高度与状态栏安全区

写信仍由首页、联系人、回复和转发共用一个全局 Material 3 Bottom Sheet，但停靠尺寸重新调整：

- 默认部分展开高度由 80% 改为 72%；
- 72% 能完整看到发件账户、收件人、主题和正文开头，同时保留来源页面关系；
- 完全展开时按状态栏高度限制 Sheet 内容，顶部圆角停在状态栏下方 8dp；
- Drag Handle 纳入 Sheet 自身测量，避免 Material 组件额外把顶部推入状态栏；
- 无论处于部分展开还是完全展开，返回键都直接关闭写信页。

## 8. 添加邮箱后缀自适应与输入光标

邮箱地址继续使用一个外轮廓容器，但右侧域名区域改为按内容测量：

- 左侧用户名区域使用剩余宽度；
- `@domain` 与展开图标始终贴紧输入框最右侧；
- 短域名保持紧凑，长域名只向左扩展，不预留过宽固定列；
- 域名区最大宽度受控，极端长后缀才使用省略；
- `BasicTextField` 光标改为主题主色，在深色输入 Surface 上清晰可见；
- Yahoo 等多后缀仍通过同一输入框右侧菜单切换。

## 9. 首次同步历史通知基线

新增账户第一次同步时，服务器返回的历史邮件用于建立本地基线，不再全部作为新邮件通知：

- 仅当账户从未成功同步、INBOX 本地无文件夹且无邮件时判定为首次基线；
- 历史邮件仍一次性写入 Room 并正常显示；
- 第一次同步向通知层返回空的新邮件集合；
- 后续真正新增的远端 UID 仍按原逻辑通知；
- UIDVALIDITY 重置也避免把整箱历史邮件再次通知。

该调整不新增数据库字段，也不会减少历史邮件保存数量。

## 10. 前后台刷新恢复与误报抑制

针对“下拉刷新后立刻退后台，回来仍在加载”以及“新账户首次同步切后台后误报无法连接服务器”增加生命周期控制：

- Activity `ON_STOP` 时立即清除 `busy` 与暂态错误；
- 每次同步分配 generation，退后台的 generation 不再有权在前台发布错误；
- JavaMail 阻塞调用可继续安全收尾，不强行在不可靠的 socket 点中断；
- 隐藏同步失败时，回到前台只安排一次受控恢复，并禁止重复错误横幅；
- 新账户尚无 `lastSyncAt` 且进程在首次同步期间被移除时，下一次前台启动会自动续接一次；
- 新的手动刷新仍可替换延迟恢复任务，避免并发建立重复 IMAP 会话。

## 11. 详情发件人头部上下间距

发件人区域不再紧贴顶部 App Bar：

- 最终 HTML 文档在 App Bar 安全区后保留 8px 顶部间距；
- 发件人头部下方同样保留 8px；
- Compose 骨架使用相同的 96dp 顶部位置、84dp 头部高度和 8dp 下间距；
- 骨架渐隐到 WebView 时不会因几何不一致发生上下跳动。

## 12. 微软邮箱状态

Outlook / Hotmail / Live 与 Microsoft 365 的服务商条目、IMAP/SMTP 端点和 OAuth 类型继续保留。本版没有把普通密码或应用专用密码冒充微软 OAuth，也没有加入缺少项目 Client ID、签名哈希与重定向配置的半成品登录流程。完整 Microsoft Entra OAuth/XOAUTH2 仍作为后续独立功能处理。

## 13. 版本与数据兼容

- `versionCode = 38`
- `versionName = 0.2.22.0`
- Room 数据库仍为 v5；
- 没有新增表、字段或迁移；
- 覆盖安装保留账户、邮件、正文缓存、联系人、发件箱、附件任务和设置。

## 14. 验证边界

交付包执行 Kotlin PSI 语法解析、JSON/XML 解析、多语言 Key/占位符一致性、实现不变量、`git diff --check`、补丁应用一致性、文件清单与 ZIP 完整性检查。当前容器没有 Android SDK，且无法取得完整 Gradle 8.11.1 与 Android/Maven 依赖，因此 Android 类型解析、Compose 编译器、Room KSP、R8、APK 构建和真机动画回归仍需在本机 Android 环境完成。
