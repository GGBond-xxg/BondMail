# BondMail v1.1.0

## OAuth 配置

- Gmail 与 Outlook 的 OAuth 公共客户端 JSON 可以随 APK 一起提供，首次使用时会自动加载。
- 用户手动导入的配置仍具有更高优先级，可随时覆盖应用内置配置。
- 内置文件只包含移动端 public client 所需信息，不包含 Client Secret、私钥、访问令牌、刷新令牌或邮箱密码。

## 启动与邮件正文

- 启动页会等到主界面完成有效布局后再退出，避免冷启动时短暂显示空白内容。
- 优化邮件 WebView 的缓存与可见帧交接，首次打开尚未缓存的邮件不再闪出空白页。
- 返回邮件列表时保留正确的工具栏和底部导航状态，避免恢复过程中的单帧跳变。

## 导航与交互

- 添加邮箱、服务商选择、账户配置、设置、关于、开源声明、应用许可和隐私条款统一使用覆盖式打开动画。
- 二级页面使用 Telegram 风格的预测性返回，手势有效区域控制在屏幕宽度约四分之一。
- 增加返回提交保护，避免部分 ColorOS 设备把一次边缘手势重复分发到新露出的页面。
- 页面跳转前先让点击水波纹、长按阴影和按压缩放回到静止状态，返回后不会继续播放上一次反馈。
- 底部“邮件 / 联系人 / 设置”恢复为普通淡入淡出，不再使用横向覆盖切换。

## 版本与兼容性

- `versionCode = 110`
- `versionName = 1.1.0`
- 本版没有数据库结构变化，覆盖安装会保留账户、邮件、正文缓存、联系人、OAuth 授权和设置。

## 发布验证

- `testDebugUnitTest`、`lintPerformance` 与 `assemblePerformance` 执行成功。
- R8、资源压缩、APK v2 签名和版本元数据检查通过。
- 优化安装包已在真实 Android 设备上覆盖安装，设备确认版本为 `1.1.0 (110)`。
- 真机依次切换邮件、联系人和设置页面，页面标题正常显示，未记录到应用致命异常。
