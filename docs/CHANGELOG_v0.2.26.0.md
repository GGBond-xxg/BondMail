# BondMail v0.2.26.0

## 通知权限交互

- 移除添加邮箱完成后自动弹出的 Android 通知权限窗口。系统权限只会在用户主动点击“允许通知”后请求。
- 自定义通知提示的两个操作改为“拒绝通知”和“允许通知”：
  - 拒绝后永久记录本次选择，不再反复提示；
  - 允许后再启动 Android 通知权限窗口；
  - 权限结果返回后同步更新本地通知开关。
- 首页无账户欢迎卡、已有邮件列表和通知提示均接入 Lazy 列表位置动画。提示展开、拒绝、授权或系统窗口返回时，下面的添加邮箱卡片/邮件会连续上移或下移，不再直接跳帧。
- 设置新增独立“权限”分组和“消息通知”状态：
  - 已授权显示“允许”，不执行点击操作；
  - 未授权显示“去授权”，点击进入当前应用的通知设置页。

## 账户输入与首页顶栏

- 添加邮箱和账户编辑中的授权码/密码字段明确请求 Password 键盘类型。
- 输入法右下角动作改为“完成”；点击后主动隐藏键盘并清除输入焦点，解决输入结束后不便收起键盘的问题。
- 首页左上角抽屉按钮移除圆形容器背景，保留点击区域、Ripple 和与顶栏共用的收起动画。

## HTML 邮件与图标

HTML 准备缓存升级为 `layout-v20`：

- 支持把 `data-src`、`data-original`、`data-lazy-src`、`data-cfsrc`、`data-srcset` 等常见延迟加载字段提升为真实图片地址。邮件中的远程图标不再依赖发件方 JavaScript 才能出现。
- 将 `//cdn.example.com/...` 形式的图片、背景、视频封面和 CSS `url()` 统一补全为 HTTPS。
- 保留小图标的明确宽高，避免对所有图片强制 `height:auto` 后导致无 `viewBox` 的小图标塌缩。
- 普通 FLUID 邮件增加谨慎的“主内容卡片扩展”判断：只有浅层、覆盖正文大部分内容且明显窄于手机视口的主容器才扩展到手机宽度；Cloudflare 等桌面 Newsletter 仍使用原有整体缩放，不破坏已经验证正常的桌面布局。
- 继续保留正文失败提示、重新加载、短邮件拖动余量以及 FLUID / DESKTOP_SCALED 双模式。

## 首次同步与正文预热

- K-9 式渐进首同步、Header/Body 分离和批量网络请求结构保持不变。
- 首次同步完成后的正文批量预取从约 280ms 提前到约 80ms，最近小邮件预取上限由 8 封提高到 12 封。
- 常规同步后的后台预取由 3 封提高到 4 封，延迟由 5 秒缩短到 3 秒。
- 仍只自动预取不超过 128 KiB 的小正文；大邮件保持按需下载，避免首轮同步被单封 Newsletter 阻塞。

## 已保留的既有实现

- Performance R8 对 Nimbus JOSE 可选 Tink/Bouncy Castle 算法引用的忽略规则。
- 163/126、QQ、iCloud、Yahoo 授权码/App Password 的 IMAP + SMTP 双协议验证后替换。
- Gmail/Microsoft OAuth 与 IMAP/SMTP XOAUTH2。
- K-9 式列表渐进显示、历史邮件通知基线、前后台同步 generation 隔离。
- WebView 空闲预热和单实例复用池。
