# BondMail v1.5.7.8

版本代码：173，支持覆盖安装。

- 新邮件通知增加最新已读状态校验：已读、已移走或已删除的邮件不再根据旧同步结果通知。
- 打开邮件、单封和批量标记已读时持久记录通知已处理状态，防止延迟 FCM 唤醒或重启后重复提醒。
- 本次同步发现的已读邮件也消耗通知记录；以后手动标为未读不会重新当作新到邮件提醒。
- 滑动切换已读／未读时，卡片背景、文字与未读标记平滑过渡，遵循应用动画开关。打开正文时仍立即更新已读，保持转场背景稳定。

验证：84 项 JVM 单元测试通过，其中 8 项通知状态回归测试。跨设备已读过滤依赖邮箱服务器已同步的状态，不能消除服务器更新前的瞬时时间差。

真机检查：连接的 vivo 已录屏验证已读→未读→已读动画；测试邮件已恢复已读。尚未现场复现低概率跨设备 FCM 时序。
