# BondMail v1.6.1.9

- 修复邮件正文圆角在深色图片上泛白的问题：在透明外层统一应用圆角遮罩，避免白色底层参与边缘混合。已对比小米 Bitget 原邮件左右圆角。
- 转发支持保留原邮件 HTML 排版、链接和图片；补充说明与原邮件分开编辑，可移除原邮件内容。
- 内嵌图片通过标准 CID 邮件资源发送，同时提供纯文本备用正文；新增附件可与 HTML 正文一起打包。
- HTML 正文贯穿发件箱、草稿同步和已发送副本，保存草稿后重新打开仍保留格式。
- 数据库从 12 升至 13，仅为发件箱增加可空 HTML 字段，保留现有邮箱数据。

版本：`versionCode 201`，`versionName 1.6.1.9`。沿用已有签名，支持覆盖安装。

测试不实际发送邮件；对 HTML、纯文本、内嵌图片、附件及草稿进行了本地 MIME 打包与重新解析验证。

验证：109 项单元测试通过；小米、vivo 各通过 10 项邮件渲染与 HTML 打包测试。圆角采用小米真实屏幕截图验证，两侧边缘均不再出现亮于深色内容的白边。
