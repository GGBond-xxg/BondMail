# 阅读与图标设置

## 正文显示模式

打开邮件 → 右上角更多 → 正文显示模式。

- 自动：保留现有移动端适配及已知模板的可读性修复。
- 原始排版：保留邮件模板样式，跳过自动深色配色修复；仍保留安全过滤与移动端布局约束。
- 浅色正文：将正文改为浅底深字，链接保持蓝色，图片与二维码像素不变。
- 纯文本：移除 HTML 视觉排版、图片和控件，显示可提取的正文文字。标题、附件入口和邮件操作保留。

默认只切换当前打开的邮件。勾选“记住此发件人的显示模式”后，同一完整发件地址的后续邮件使用该模式；选择“恢复此发件人的默认显示”会删除记忆并切回自动。

切换仅影响本地阅读，不修改原邮件、不发送正文到额外服务。已显示译文时，显示模式应用于当前译文。原文/译文切换继续使用现有翻译按钮。

## 手动图标分类

长按邮件列表头像，或打开邮件 → 更多 → 图标分类。普通点按列表头像仍打开邮件。

支持 AI / 人工智能、银行、运营商 / SIM、交易所、运动、服饰、购物、酒店、快递和航空。

- 仅此邮箱地址：只影响该完整地址。
- 此域名下的所有邮箱：影响同一精确域名，不包含子域名。例如 mail.example.com 与 example.com 是两个范围。
- 地址规则优先于域名规则；手动分类优先于自动品牌图标及联系人文字头像。
- 选择“恢复自动识别”会移除当前所选范围的规则。如果仍有域名规则，则继续继承该域名设置；要完全恢复自动识别，请同时移除相关地址和域名规则。

列表的已发送邮件按显示的收件人应用图标规则；详情菜单按详情头部发件人应用规则。设置保存在本机，重新打开应用仍有效。头像继续跟随当前主题色。
