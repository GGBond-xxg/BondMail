# 阅读与图标设置

## 邮件缩放与宽版正文

仅正文支持双指张开放大、捏合缩小；放大后可以左右移动查看。右上角“更多”也提供“放大正文”“缩小正文”“恢复默认缩放”。范围为默认适配尺寸的 25%–500%，允许缩到默认以下查看宽表格；恢复默认回到 100%。主题、发件人和应用工具栏始终保持原尺寸。

正文偏离默认比例时，在浮动操作区上排右侧显示“恢复默认缩放”，点击后恢复并隐藏。下排左侧为“加载图片”，右侧固定为“查看原文 / 复制验证码 / 翻译（进行中为取消）”；右侧不可用的操作保留位置，图片加载完成或翻译进度变化不会移动复制按钮。验证码复制成功或失败都显示明确提示，不依赖系统剪贴板浮层。

固定宽度邮件先保留完整画布，再整体适配屏幕；真实响应式邮件继续使用移动布局。国泰的 700px 账单在日间保留固定画布；夜间自动模式检测到完整的手机宽度与分栏堆叠规则时，使用与浏览器预览一致的移动布局，避免再次整体缩小字号。规则不完整的账单仍保留固定画布，普通流式国泰邮件不强制缩小。单独声明手机 viewport 不足以证明固定宽度表格能够响应式排版。

正文遇到未识别的横向溢出时允许左右滚动，避免被卡片直接裁掉。缩放手势不触发顶部拉伸或隐藏工具栏，正文缩放保持阅读锚点；在标题/发件人区域捏合不会改变正文。缩放只改变本地显示，不改变原邮件或远程图片加载策略。

实现使用原生手势检测和应用固定的 DOM 样式更新，只缩放 `bondmail-message-body`，禁用 WebView 整页缩放。净化文档移除发送方脚本与事件属性，文档首项 CSP 使用 `script-src 'none'` 并禁止框架、对象、连接和表单；WebView 允许应用自身的 `evaluateJavascript` 调整样式，不允许发送方脚本执行，也不暴露 JavaScript 桥接。设备测试覆盖 CSP 脚本/事件阻断、默认以下缩小、头部尺寸稳定和手势互斥。

## 正文显示模式

打开邮件 → 右上角更多 → 正文显示模式。

- 自动：保留现有移动端适配及已知模板的可读性修复。夜间模式下，根据 WebView 实际计算的背景和文字颜色转换正文，浅色面板变为深色，灰阶正文以 7:1、彩色文字及链接以至少 4.5:1 的对比度为目标调整；普通图片、二维码和 SVG 不做整体反色，透明素材保留适合原配色的衬底；已验证小图标的例外见下文。背景图上的文字使用局部深色衬底，隐藏预览文字仍隐藏。
- 原始排版：保留邮件模板样式，跳过自动深色配色修复；仍保留安全过滤与移动端布局约束。
- 浅色正文：将正文改为浅底深字，链接保持蓝色，图片与二维码像素不变。
- 纯文本：移除 HTML 视觉排版、图片和控件，显示可提取的正文文字。标题、附件入口和邮件操作保留。

默认只切换当前打开的邮件。勾选“记住此发件人的显示模式”后，同一完整发件地址的后续邮件使用该模式；选择“恢复此发件人的默认显示”会删除记忆并切回自动。

切换仅影响本地阅读，不修改原邮件、不发送正文到额外服务。已显示译文时，显示模式应用于当前译文。原文/译文切换继续使用现有翻译按钮。

夜间配色只对“自动”模式启用，在正文揭开加载遮罩之前完成；日间模式、原始排版及浅色正文不会运行配色转换。切回日间会加载独立缓存的原配色文档。图片内自带的白底和文字保留原样，复杂模板仍可通过“浅色正文”或“原始排版”查看。

夜间白纸背景转为接近黑色，彩色链接在保证对比度的前提下保留品牌色。已核对来源和透明像素的国泰标志、会员及里数等小图标免加白色衬底：单色图标提亮为浅色，彩色图标保留色相并提亮。此处理严格限定到已验证的资源地址，不套用到二维码、照片或其他发件人的图片。

## 手动图标分类

长按邮件列表头像，或打开邮件 → 更多 → 图标分类。普通点按列表头像仍打开邮件。

支持 20 类：AI、银行、运营商 / SIM、交易所、运动、服饰、购物、酒店、快递、航空、支付 / 钱包、社交、游戏、影音、教育 / 学习、餐饮、地面出行、医疗 / 健康、招聘 / 工作、软件 / 开发工具。

- 仅此邮箱地址：只影响该完整地址。
- 此域名下的所有邮箱：影响同一精确域名，不包含子域名。例如 mail.example.com 与 example.com 是两个范围。
- 地址规则优先于域名规则；手动分类优先于自动品牌图标及联系人文字头像。
- 选择“恢复自动识别”会移除当前所选范围的规则。如果仍有域名规则，则继续继承该域名设置；要完全恢复自动识别，请同时移除相关地址和域名规则。

列表的已发送邮件按显示的收件人应用图标规则；详情菜单按详情头部发件人应用规则。设置保存在本机，重新打开应用仍有效。头像继续跟随当前主题色。
