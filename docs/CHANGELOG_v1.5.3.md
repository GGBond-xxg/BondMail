# BondMail v1.5.3

- 翻译直接显示在原邮件 HTML 中，保留表格、图片、链接与样式，同时翻译标题；支持一键显示原文。
- 顶部依次为返回、邮箱名称、翻译语言（地球）、翻译服务密钥、收藏、更多；邮箱工具移入更多。
- 翻译与原文按钮共用同一个圆形组件：58dp 按钮、24dp 图标，背景与阴影一致。
- 翻译按钮位于右下角删除按钮上方，翻译后在左侧显示原文按钮；下方回复、转发、分享、删除保持不变。
- 首页、联系人和邮件详情共用悬浮按钮位移动画：底部操作栏下滑隐藏时，悬浮按钮下移；回滑恢复。
- 修复 iFAST 深色模式页脚文字对比度；Aleta Adventure 使用通用银行图标。
- HTML 翻译只发送可见文字，跳过脚本、样式、隐藏区域及免翻译区域。重复文字去重、加密缓存、进度与取消支持；失败不覆盖原邮件。

版本号 1.5.3，内部版本号 148，沿用原签名，可覆盖更新。
