# BondMail v0.2.39.0

发布日期：2026-07-27

基线版本：v0.2.38.0

版本号：`versionCode 60` / `versionName 0.2.39.0`

## 1. 桌面图标视觉尺寸恢复正常

- Adaptive Icon 的彩色前景和 Android 13+ monochrome 前景统一增加 `10dp` 安全内边距。
- Android 8 以下使用的 mdpi～xxxhdpi 方形/圆形图标保持原画布和原背景，只把信封主体缩小约 18%。
- 启动器、应用列表、圆形图标、主题图标和启动页不再出现信封几乎贴满图标格子的情况。
- 未更换用户确认过的图标设计，仅调整内部主体比例。

## 2. Apple 邮件顶部 Logo 不再钻进发件人区域

- 新增 Apple/Apple ID/iCloud 发件人识别。
- 对 Apple 邮件首个可信品牌图及其有限祖先节点进行定向归一化，清除绝对定位、负顶部偏移和 transform 带来的越界。
- HTML 隐藏发件人占位层改为与内容卡一致的不透明背景，阻止任何正文图层透过头像/发件人区域。
- 修复只作用于 Apple 发件人路径，普通邮件的图片、按钮和排版不受影响。

## 3. OKX 夜间模式恢复原邮件明暗关系

- 新增 OKX、OKEX、OKCoin 发件人识别。
- 深色主题下，以上邮件不再启用 WebView 算法深色化，避免原模板中“黑色区 + 白色区”被二次改色后出现白底白字。
- 邮件正文保留原始浅色画布和深色默认文字；应用顶栏、页面背景和底部操作栏继续使用当前深色主题。
- 其他发件人的算法深色化逻辑保持不变。

## 4. 正文加载改成半透明骨架屏

- 删除邮件内容中央的 `40dp CircularProgressIndicator`，详情页只保留一套加载反馈。
- 已经取得的摘要文本以约 46% 透明度留在最终位置，骨架条以半透明方式覆盖在文字上方。
- 骨架条根据摘要长度显示 6～8 条；无摘要时固定显示 7 条，不再只有 3 条。
- 骨架层和占位卡共同淡出，不会在卡片尚未收缩完成时先消失。

## 5. 附件位置与短邮件收缩动画同步

- 加载布局和最终 HTML 统一为：`发件人 → 附件 → 正文`。
- 已解析到的附件从第一帧起直接显示在发件人下方，不会先出现在骨架底部，加载完成后再瞬移到顶部。
- 最终 HTML 也把附件节点放在正文之前，两个布局的纵向顺序保持一致。
- 短邮件不再用固定延迟猜测动画进度；占位卡的高度弹簧真正结束后才开始揭示 WebView。
- 附件、骨架/正文和外层边框共享同一几何过渡，解决内容已经到位、边框仍持续向上收缩的问题。
- HTML 准备缓存升级为 `layout-v34`，避免复用旧版排版结果。

## 数据与兼容性

- Room 仍为 v8，不需要数据库迁移。
- MIME parser 仍为 v8。
- Gmail、Microsoft OAuth、授权码账户、已读/星标、附件元数据和现有缓存不会因覆盖安装被清除。
- IMAP ID 客户端版本同步更新为 `0.2.39.0`。

```powershell
.\gradlew.bat --stop

```
