# BondMail v1.6.0

- 新增桌面小组件：2×2、4×2、4×4 默认尺寸，支持桌面拉伸。
- MIUI / HyperOS、Material 3、Liquid Glass 三套独立外观，支持浅色、深色和跟随系统。
- 每个实例可选择账号、显示项目和隐私模式，配置页提供真实邮件预览；入口位于设置 → 桌面小组件。
- 未读数和最近邮件接入本地数据库，支持打开对应账号收件箱、阅读邮件、写邮件和手动刷新。
- 隐藏内容同时从桌面文本和无障碍说明中移除；账号删除/停用后清空显示。
- 数据变化合并更新，手动刷新按账号去重；离线保留缓存，不新增周期性网络同步任务。
- 支持三语言、系统字体放大和可用空间不足时自动减少内容。Glass 使用透明玻璃层和细高光边缘，直接透出桌面壁纸，不添加背景图片。

使用方法、适配范围和技术说明见 [桌面小组件](WIDGETS.md)。本轮设备验证仅使用 vivo Android 15，小米由用户手动测试。
