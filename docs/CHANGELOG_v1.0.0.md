# BondMail v1.0.0

## 账户与联系人

- 新增通用 IMAP/SMTP 登录，可配置服务器、端口、连接安全与验证方式，并在保存前同时验证收信和发信。
- Gmail 与 Microsoft 继续使用 OAuth；163、126 等邮箱支持客户端授权码。
- 账户头像和联系人头像支持自动品牌图标、单字或 Emoji，自定义结果全局生效。
- 邮箱显示地址允许调整字母大小写，但不允许替换实际邮箱。
- 联系人支持添加、编辑和删除；删除只移除本地联系人资料，不影响邮件。

## 后台收信与通知

- 1、5、10 分钟同步使用前台服务保持后台检查，15 分钟使用系统周期任务。
- 新邮件提醒与“后台收信”常驻提示使用独立通知频道，可单独关闭常驻提示。
- 修正通知小图标与通知权限状态文案。
- 增加开机恢复和后台同步调度，降低应用退出前台后漏收提醒的概率。

## 界面、动画与正文

- 搜索时自动隐藏底部导航，首页、联系人和设置滑动时使用一致的导航收起/恢复逻辑。
- 三个主页面使用动态底部安全区，导航隐藏后不再保留大块空白。
- 点击反馈、圆角和阴影形状保持一致。
- 优化长邮件主题测量与安全区，避免主题被发件人区域覆盖。
- 调整 Apple、Newsletter 等 HTML 邮件的深色模式、尾部留白与正文缩放。
- 改善冷启动首次打开邮件时的 WebView 预热与可见帧切换。
- 补充 163、126、OpenAI/ChatGPT 等品牌头像，并修正 Apple 图标对齐。

## 设置与项目信息

- 设置页改为紧凑卡片分组，选择项支持自动换行，权限说明并入对应入口。
- 新增“关于 BondMail”页面，显示 `V1.0.0`、项目简介、开源声明、MIT 应用许可、隐私条款和 GitHub 项目主页。
- 根目录加入 MIT `LICENSE`。
- 应用版本更新为 `versionCode 100`、`versionName 1.0.0`。

## 发布验证

- `assemblePerformance` 构建通过，R8 与资源收缩开启。
- `lintPerformance` 完整检查通过。
- 性能版 APK 已在真实 Android 设备上覆盖安装，保留原有账户与邮件数据。
- 已验证冷启动、收件箱、联系人末尾、设置末尾、关于页、开源声明、应用许可和隐私条款；验证期间未出现崩溃。
