# 通用图标素材清单

现有通用图标：AI、银行、运营商 / SIM、交易所、运动、服饰、购物、酒店、快递、航空。

以下十类素材已于 v1.5.6.2 接入长按头像的手动分类菜单。已有品牌专属图标继续保留；本次不新增基于邮件正文或模糊关键词的自动分类。

| 类别 | 建议文件名 | 图形建议 |
| --- | --- | --- |
| 支付 / 钱包 | Wallet.svg | 钱包或银行卡 |
| 社交 | Social.svg | 对话气泡 |
| 游戏 | Gaming.svg | 游戏手柄 |
| 影音 / 订阅 | Entertainment.svg | 播放按钮 |
| 教育 / 学习 | Education.svg | 书本或学士帽 |
| 餐饮 | Food.svg | 餐具 |
| 地面出行 | Transport.svg | 公交或火车 |
| 医疗 / 健康 | Health.svg | 心形与心电线 |
| 招聘 / 工作 | Jobs.svg | 公文包 |
| 软件 / 开发工具 | Developer.svg | 代码括号 |

十份源文件均保留在 ICON 目录；打包资源采用小写文件名，并明确继承的填充、描边与镂空样式。后续新增素材仍建议使用透明背景、单色、缩小后清晰的 SVG。
