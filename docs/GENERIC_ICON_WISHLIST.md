# 通用图标待补清单

现有通用图标：AI、银行、运营商 / SIM、交易所、运动、服饰、购物、酒店、快递、航空。

下面是尚无通用图标的常见类别，不代表已接入自动识别。已有品牌专属图标继续保留。

| 类别 | 建议文件名 | 图形建议 |
| --- | --- | --- |
| 支付 / 钱包 | Wallet.svg | 钱包或银行卡 |
| 社交 | Social.svg | 对话气泡 |
| 游戏 | Gaming.svg | 游戏手柄 |
| 影音 / 订阅 | Entertainment.svg | 播放按钮 |
| 教育 / 学习 | Education.svg | 书本或学士帽 |
| 餐饮 | Food.svg | 餐具 |
| 地面出行 | Transport.svg | 公交或火车 |
| 医疗 / 健康 | Health.svg | 心形与心电线 |
| 招聘 / 工作 | Jobs.svg | 公文包 |
| 软件 / 开发工具 | Developer.svg | 代码括号 |

可先补支付、社交、游戏、影音、教育五类。选透明背景、单色实心路径、缩小后仍清晰的 SVG；避免自带大底板、嵌入位图或仅用 text 元素绘制字样。文件放进 ICON 目录后再接入分类。
