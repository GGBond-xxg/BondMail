# v1.5.5.4

- 修复超大邮件整行读取触发 SQLiteBlobTooBigException、导致滚动停留后闪退的问题。正文与附件描述按 64 KiB 分块读取，保留完整内容和现有数据；覆盖单封、批量、文件夹、发件人查询及详情订阅。

- Outlook 联系人图标改为适配主题的单色轮廓，避免多层彩色 SVG 染成实心块。
- 提供 Windows ADB 日志采集脚本。

验证：51 项 JVM 测试通过，Debug 和 Android 测试包编译通过。新增超大邮件回归测试，但模拟器测试期间电脑重启，未取得运行结果；仍需在原问题手机上复测。
