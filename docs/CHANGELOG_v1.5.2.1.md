# BondMail v1.5.2.1

修复 v1.5.2 的发件人图标显示回退，并完善邮件翻译。

- 恢复已处理图标的最高优先级，避免原始 SVG 的背景圆/方块在统一染色后遮住 Logo。
- 修复 MEXC、iFAST、Cloudflare 等受影响的图标，并保留 QQ Mail、Gmail、Yahoo 与新服务商的图标支持。
- 图标同步脚本保留已修正的根目录 SVG，仅补充缺失图标；移除生成目录中的重复副本，防止再次覆盖。
- 增加加载优先级与实际图标几何边界回归检查，不再只验证“图标能加载”。

- 邮件标题和正文一起翻译；切回原文后恢复原标题，不修改原始邮件或回复/转发内容。
- 翻译服务与目标语言并排显示；改用“译文 / 对照 / 原文”选项，移除含义不明的复选框。
- 长译文单独滚动，底部操作按钮固定显示，避免被正文挤出窗口。

版本号：1.5.2.1；内部版本号：147。沿用原签名，可直接覆盖更新，保留账号与邮件数据。

验证：34 项 JVM 测试、2 项真机图标测试通过；MEXC、iFAST、Cloudflare 的解析后图形已离屏绘制检查。确认 202 个已处理 SVG 保持原内容、生成目录不存在同名覆盖，图标同步重复执行结果一致。
