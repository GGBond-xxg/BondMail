# BondMail v1.6.1.5

- 邮件详情顶部采用与首页一致的 Glass 背景效果。向后阅读时顶部栏和底部操作栏一起收起，反向滚动时重新出现。
- 正文滚动区域延伸至顶部，顶部栏收起后不再留下固定空白，重新出现时可透出下面的邮件内容。
- 移除首页侧边菜单底部重复的“设置”入口。
- 修复侧边菜单进入“添加邮箱”后返回时，菜单短暂闪现再消失的问题。现在先完成菜单关闭，再捕获首页作为返回动画背景并进入添加页面。

版本：`versionCode 197`，`versionName 1.6.1.5`。沿用已有签名，支持覆盖安装。

验证：103 项单元测试通过；vivo V2310 / Android 15 上完成 8 项真机回归，覆盖深浅主题下的顶部和底部同步显隐、正文完整滚动区域、邮件操作、网页排版，以及菜单返回和取消返回后的关闭状态。Glass 透视效果与返回手势中间帧已人工检查；优化 APK 构建及 release lint vital 检查通过。
