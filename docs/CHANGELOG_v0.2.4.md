# BondMail v0.2.4

## 真机反馈修复

- 邮件卡片点击恢复，长按进入多选。
- 右向左滑动根据当前状态切换已读/未读。
- 深色模式状态栏与导航栏图标自动切换明暗。
- Navigation Compose 预测性返回改为官方 `scaleOut(0.9f)` 示例。
- 写邮件页面使用预热 ViewModel，减少首帧闪烁。
- IMAP/SMTP 连接失败时自动进行一次 TLS 1.2 兼容重试。
- 添加邮箱页改为左宽右窄的同高输入块；单后缀邮箱不显示无意义下拉菜单。
- 语言选择改为竖向单选列表。
- 抽屉宽度为屏幕 80%，账户默认只显示前三个，可展开/收起。
- 新增邮箱排序页面，数据库升级到 v4；排序应用于所有账户列表。
- 底部导航改成覆盖内容的悬浮 Dock，并缩小按钮。
