# BondMail v1.6.1.2

- 统一应用内页面的预测性返回：拖动时当前页面缩成圆角卡片，露出上一页；松手后退出，取消手势则恢复原位。邮件详情、设置子页、账户添加、关于及许可页共用同一实现。
- Liquid Glass 调节从全屏 Dialog 改为导航页面；桌面小组件管理从独立 Activity 改为应用内导航。两个入口使用一致的进入和返回动画，不再依赖各厂商的跨 Activity 动画样式。
- 小组件尺寸配置、已有小组件编辑使用相同的返回效果，返回时回到管理页。保留桌面启动器配置入口及其结果回传。
- 修复回复技能列表抢先消费系统返回事件的问题，使页面容器能接收预测性返回进度。
- 顶部返回按钮和没有手势进度的返回事件也使用同一套卡片退出动画；保留系统关闭动画设置。

版本：`versionCode 194`，`versionName 1.6.1.2`。APK 沿用 v1.6.1.1 签名，支持覆盖安装。

验证：99 项单元测试通过；vivo V2310 / Android 15 上的卡片预览、左右侧返回、取消后触摸恢复、无进度返回和许可页滚动位置回归通过。最终优化 APK 已覆盖安装，实际验证 Liquid Glass 调节、小组件管理与尺寸配置的进入/返回，并通过录屏检查圆角缩放预览。构建及 release lint vital 检查通过。

说明：应用内动画由 BondMail 绘制；实时跟手仍需要系统提供预测性返回进度。返回桌面、启动器和外部应用的系统动画由 Android/厂商管理。小米的系统进度回调情况需要用此版本实机确认。
