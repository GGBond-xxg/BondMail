# v1.6.4

- 夜间自动模式根据邮件实际背景和文字颜色适配深色正文，改善浅色邮件刺眼、文字与背景对比不足的问题；隐藏预览文字继续隐藏，普通图片与二维码不做整体反色。
- 国泰账单在具备完整手机样式时使用夜间移动布局，改善字号、边距、分栏和横向溢出；修正标志尺寸，并为已验证的透明小图标适配深色背景。日间保留原有配色和排版。
- 邮件正文支持双指缩放及菜单放大、缩小、恢复默认，范围为 25%–500%；标题、发件人和工具栏保持原尺寸。
- 调整阅读页浮动操作区，翻译进度与原文切换不再挤动复制按钮；复制验证码成功或失败均提供明确提示。

版本：`1.6.4`，`versionCode 220`，最低支持 Android 8.0。

验证：113 项单元测试、30 项设备测试通过，包含日夜切换、正文缩放、40 个发件域的缓存邮件可读性及日间配色检查；实际国泰邮件已对照 Via 浏览器核对手机排版。

沿用上一版签名，可直接覆盖安装，保留邮箱、联系人和设置数据。
