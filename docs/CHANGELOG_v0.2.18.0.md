# BondMail v0.2.18.0

本版针对 v0.2.17.1 真机录屏继续修复搜索转场闪烁、滚动顶栏透明、写信操作重复、抄送/密送布局、快捷邮箱提示常驻、写信返回层级，以及进程冷启动后首次打开 HTML 邮件的卡顿。

## 1. 搜索按钮改为单一容器变形

- 顶栏不再同时维护“原搜索按钮”和“动画搜索按钮”两套可见组件。
- 顶栏只保留一个 `44dp` 定位槽；实际搜索按钮和展开后的搜索框由同一个 `Surface` 绘制。
- 收起状态下，该 Surface 就是普通圆形搜索按钮；点击后直接从当前位置扩展为完整搜索框。
- X/Y、宽度、高度、圆角、图标位置、阴影、遮罩及内容透明度由同一个 `Animatable` 进度驱动。
- 关闭时先完整收回原按钮位置，再清理查询、焦点和键盘，避免窗口尺寸变化打断逆向动画。
- 搜索结果进入邮件详情前会先完成关闭转场，避免搜索动画与页面导航动画重叠。
- 搜索按钮会跟随顶栏的屏幕外位移，不再在顶栏收回时独立停留或闪现。

## 2. 顶栏恢复实体背景

- 首页顶栏改为不透明 `surfaceContainerLow` Surface。
- 邮件详情顶栏改为不透明 `surfaceContainer` Surface。
- 两者保留轻微阴影分层，滚动隐藏/恢复时不会再让邮件内容透到底下造成文字重叠。
- 顶栏仍保持固定布局，只通过 `graphicsLayer.translationY` 进入/退出屏幕，不触发列表重测。

## 3. 写信页操作精简

- 删除底部发送按钮，只保留右上角发送动作。
- 删除正文区域的大型“添加附件”按钮。
- 附件入口移动到右上角回形针图标；达到 10 个附件后自动禁用。
- 右上角附件图标显示当前附件数量角标。
- 已选择附件继续以 Chip 显示，支持查看名称、大小和逐个移除。
- 顶栏高度在发送中和选择附件时保持稳定，不因操作状态改变布局。

## 4. 收件人、抄送和密送

- 默认只显示“收件人”输入框。
- 收件人右侧增加展开/收起图标。
- 点击后在同一区域下方显示“抄送”和“密送”，再次点击收起。
- 抄送/密送使用短时 Fade + Expand 动画，不单独占据常驻区域。
- 每次从首页、联系人、回复或转发新开写信抽屉时，都会重新初始化草稿状态，避免上一封草稿短暂闪现。

## 5. 快捷邮箱后缀改为上下文提示

- `@gmail.com`、`@outlook.com`、`@qq.com`、`@163.com`、`@icloud.com` 不再长期占据一行。
- 仅当收件人输入框获得焦点且当前地址片段尚未完成时显示。
- 已输入 `@` 时会根据已输入域名过滤建议。
- 完整匹配常用域名、输入片段为空、存在空格或输入框失去焦点后，提示自动消失。
- 最多显示三个最相关建议，容器色调整为低对比层级。

## 6. 写信返回行为

- 无论抽屉处于约 80% 高度还是全屏展开状态，系统返回键都直接关闭写信抽屉并回到来源页面。
- 不再先从全屏退回 80%，再要求第二次返回。
- 手势仍保留：上滑可展开，下滑可关闭。
- 首页写信、联系人写信、详情回复和详情转发继续共用同一个全局 Bottom Sheet。

## 7. 首次打开邮件性能

- 新增单实例 `MailWebViewPool`，只缓存一个脱离界面的邮件 WebView。
- 首页首帧完成后，等待列表保持空闲，再初始化 Chromium 和一张透明本地页面。
- 冷启动关键路径不创建 WebView，避免重新出现开屏白帧。
- App 回到前台后，如缓存曾因内存压力被释放，会在新的空闲窗口重新预热。
- 第一次点击发生在预热完成前时，先完成原生详情壳层 Forward 动画，再挂载 WebView，避免 Chromium 初始化和页面移动争抢同一帧。
- 离开详情后会停止加载、解除回调、清空旧文档并把 WebView 放回单实例池。
- 系统报告中度以上内存压力时销毁脱离界面的缓存，不影响当前正在显示的邮件。

## 8. Forward / Backward 导航稳定性

- 邮件列表保持为稳定的后层页面，不再在进入详情时同步缩放整张 LazyColumn。
- 详情页只做小距离 Forward 位移和淡入；返回严格反向。
- Android 预测性返回揭示的是已经绘制好的首页，而不是临时重新组合的列表。
- WebView 永远不参加页面缩放、共享边界或尺寸动画。

- Room 数据库版本仍为 v5，本版没有新增表或字段，不会再次迁移或清除本地数据。
