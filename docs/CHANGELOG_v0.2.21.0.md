# BondMail v0.2.21.0

本版根据 `长按取消.mp4`、`暂无邮件.mp4`、Gmail 浅色/深色模式对比图和 Yahoo 添加邮箱截图继续调整。重点是消除退出选择模式时的 `0 已选择` 闪帧、让文件夹切换始终保留缓存或稳定空状态、恢复 Gmail 首尾分组圆角，并把动态取色 Surface 层级抽成全局可复用主题模块。

## 1. 取消最后一个勾选时不再闪出“0 已选择”

旧实现直接读取 `selectedIds.size`。最后一个邮件取消勾选后，`AnimatedContent` 的选择工具栏仍处于离场淡出阶段，但列表已经变成空集合，因此离场内容会短暂重新绘制为 `0 已选择`。

本版：

- 选择工具栏保存最后一次非零数量；
- 选择模式仍存在时显示实时数量；
- 退出选择模式的淡出阶段显示最后一个有效数量，而不是 0；
- 邮件选中背景使用短时颜色动画恢复普通 Surface，取消勾选不再硬切。

删除、标记已读、返回键退出选择模式和长按入口的业务逻辑不变。

## 2. 已发送、草稿、垃圾邮件等文件夹不再出现空白等待帧

`HomeViewModel` 新增按“账户 + 文件夹”区分的内存快照缓存：

- 首次仍以 Room 作为持久缓存来源；
- 每次 Room Flow 发出数据时同步更新对应内存快照；
- 点击文件夹或从抽屉切换邮箱/文件夹时，先读取内存或 Room 快照，再提交可见选择；
- `selectedAccount` 与 `folder` 连续变化时抑制中间组合状态，避免先短暂加载错误账户/文件夹；
- 有缓存立即显示邮件；无邮件立即稳定显示“暂无邮件”；不再先绘制一个什么都没有的空页面。

搜索与网络同步逻辑不变，后台同步后 Room Flow 仍会自动刷新当前列表。

## 3. 邮件、联系人和搜索结果采用 Gmail 首尾分组圆角

`MailContentDefaults` 现在统一生成四种几何状态：

- 单条：四角均为 24dp；
- 第一条：左上、右上 24dp，底部 5dp；
- 中间条目：四角 5dp；
- 最后一条：顶部 5dp，左下、右下 24dp。

邮件列表、联系人列表、搜索结果和左右滑动背景使用同一个 Shape，避免卡片和手势背景圆角不一致。3dp 行间距与 10dp 左右留白继续保留。

## 4. 全局动态取色 Surface 模块

新增 `BondMailSurfacePalette`，不再由每个页面自行挑选接近但不同的 Material 3 Surface：

- `page`：页面画布；
- `chrome`：顶部标题/搜索区域；
- `content` / `contentUnread`：邮件、联系人和主要内容卡片；
- `dock`：底部导航和详情操作栏；
- `section`：文件夹 Chip、抽屉账户行和次级分组；
- `popup`：搜索容器、刷新指示器和悬浮菜单；
- `input`：输入框与搜索框；
- `drawer`：侧边抽屉；
- `sheet`：写邮件底部抽屉。

浅色、深色和 Monet 动态取色均由同一映射生成。页面背景与顶部 Chrome 使用相同的带色画布，内容卡片使用更低层 Surface，因此浅色模式不会与底部融成一片，深色模式也能保持 Gmail 对比图中的深浅层级。

该主题层级已应用到：首页、联系人、设置、抽屉、写邮件、邮件详情、服务商选择和添加邮箱页面。

## 5. 添加邮箱改为单一邮箱输入框

Yahoo、QQ、163、126、iCloud 等带预设后缀的服务商不再显示两个并排圆角框：

- 左侧仍输入邮箱用户名；
- 右侧在同一个外框内固定显示 `@domain`；
- 多后缀服务商在最右侧显示展开图标；
- 点击右侧区域打开后缀菜单；
- 整个控件只保留一条外轮廓，焦点和菜单展开共用同一高亮边框；
- 粘贴完整邮箱时会自动拆分用户名与已支持后缀；
- 无预设后缀的通用服务商继续在同一输入框内保留完整邮箱地址。

这避免了小屏幕上左右两个字段互相挤压，以及 `@yahoo.co...` 一类不必要的提前截断。
