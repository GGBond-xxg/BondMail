# BondMail v0.2.5

本版本只集中处理界面、动效与邮件正文夜间显示，不调整账户数据库结构。

- 修复首页、联系人、设置页与系统状态栏重叠。
- 邮箱分类改为列表顶部内容，滚动时自然离开。
- 分类按钮改为图标居中、选中后向右平滑展开文字。
- 搜索改为顶部下拉式搜索面板。
- 添加邮箱用户名与域名改为同高双块，域名列表原位向下展开。
- 左右滑动操作背景预先放置图标，避免滑动途中突然出现或切换。
- 新页面使用轻量缩放淡入，返回使用 Navigation Compose 官方 predictive-back 缩小退出方式。
- HTML 邮件夜间模式增加 WebView algorithmic darkening 与硬编码文字颜色清理。
- WebView 开启离屏预栅格，正文首帧显示后平滑淡入。
- 底部悬浮导航避让系统导航栏。
