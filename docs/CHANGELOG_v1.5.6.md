# BondMail v1.5.6

- 新增正文显示模式：自动、原始排版、浅色正文和纯文本。可单次切换、记住发件人偏好，或恢复默认。
- 新增手动图标分类：长按邮件列表头像或通过详情“更多”设置，可按邮箱地址或精确域名应用。地址规则优先，支持恢复自动识别。
- 银行、运营商 / SIM、交易所、运动、服饰、购物、酒店、快递和航空共用现有本地图标与主题色。
- 显示模式只改变本地阅读呈现，不修改原邮件；浅色正文保留图片和二维码，当前译文也可切换显示模式。

版本代码：162。最低 Android 8.0。

验证：66 项 JVM 测试通过；三种语言的新增文案一致，九类图标资源齐全。本版尚未进行真机复测。
