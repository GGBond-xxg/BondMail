# BondMail v1.6.1.4

- 邮件详情时间固定右对齐，与信息卡右侧内容边缘对齐。附件按钮移到下方地址区域，附件加载完成后也不会挤动时间。
- 将主题和发件人信息整理为统一圆角卡片，增加底部留白，并与正文保留 12 dp 间距，解决邮件信息与正文紧贴的问题。
- 同步原生信息卡、加载占位和邮件网页层的布局尺寸，保持加载前后及滚动时的衔接一致；保留原邮件正文的排版和缩放方式。
- 调整长标题测量宽度，并为大字体保留足够的发件人信息高度。

版本：`versionCode 196`，`versionName 1.6.1.4`。沿用已有签名，支持覆盖安装。

验证：103 项单元测试通过；vivo V2310 / Android 15 上 7 项仪器测试通过，覆盖时间右对齐、附件加载前后位置稳定、附件点击、大字体和真实 WebView 的卡片间距，以及已有邮件排版回归。浅色、深色、两行长标题、1.6 倍字体截图及实际邮件滚动已检查。优化 APK 构建与 release lint vital 检查通过。
