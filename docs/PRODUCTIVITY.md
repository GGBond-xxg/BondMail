# 邮箱效率功能

v1.5.2 在 v1.5.1.1 基础上增加以下功能。同步设置顺序为：同步频率、CF 推送、工具、翻译。

| 功能 | 入口与行为 |
|---|---|
| 多服务商翻译 | 设置 → 翻译服务；阿里云、网易有道、Google、Microsoft 独立密钥。测试发送固定 Hello. 短句，可能消耗少量额度 |
| 译文缓存与对照 | 标题与正文一起翻译，可在邮件中查看；支持译文、对照、原文三种视图。服务与语言并排选择，长内容滚动，操作按钮固定；保留原文链接，顶部翻译按钮恢复原标题与正文。缓存按文本+服务商+目标语言区分、AES-GCM 加密、上限 20 MiB |
| 撤销发送 | 点击发送后预留 10 秒，各页面底部显示撤销提示，首页也显示发送队列；撤销后回到本地草稿。截止时间持久化，数据库原子状态检查避免与发送竞争。SMTP 开始后不能撤回；进程在发送中中断时显示“结果待确认”，不自动重复提交 |
| 搜索筛选 | `from:name@example.com after:2026-01-01 before:2026-02-01 has:attachment 关键词`；日期采用设备时区，after 包含当天，before 不包含当天；每批增加 100 条，最多 10,000 条 |
| 同步诊断 | 设置 → 邮箱工具 → 同步诊断；各账号最近同步时间/错误、IMAP/SMTP 配置、单账号重新同步。授权失效通过现有账号编辑页面处理 |
| 签名与模板 | 邮箱工具 → 账号偏好；按账号保存。模板用单独一行 `---` 分隔。写信页面手动插入签名或模板，避免切换账号时覆盖编辑内容 |
| 通知分级 | 账号偏好：全部、仅重要、全部静音、关闭；重要/静音规则支持完整邮箱及 `@domain`，只匹配精确域名。静音规则优先；显式设置的稍后提醒不受收信规则过滤 |
| 附件中心 | 邮箱工具 → 附件中心；按账号、最近 7/30 天、文件名/MIME 类型筛选。已下载文件直接打开，其余打开所属邮件查看/下载；不批量下载，不自动删除用户下载文件 |
| 会话 | 邮箱工具 → 邮件会话；按 Message-ID、In-Reply-To、References 连通关系聚合，严格隔离账号，不按相同主题误合并。回复发送及草稿保留相关邮件头 |
| 引用折叠 | Gmail、Yahoo 与标准 `blockquote[type=cite]` 回复块默认折叠，点击 `···` 展开；普通引用段落保留 |
| 稍后提醒 | 邮件详情 → 工具：1 小时、1 天或 1 周后提醒，可在列表取消；WorkManager 持久化任务，不移动服务器邮件 |
| 存储管理 | 邮箱工具 → 存储管理；分别查看/清理远程正文、译文和 WebView 资源缓存。保留本地草稿、待发邮件、账号、元数据及外部下载附件 |

## 行为边界

- 所有列表、会话、附件与搜索基于已同步到手机的邮件。会话/附件索引默认加载 200 封，再逐批加载。旧缓存未包含回复头时，需要重新同步相关邮件。
- 搜索保留 SQLite 参数化子串匹配，以支持中文与标点；未强行启用默认 FTS 英文分词。大规模全文索引需要另行评估中文 tokenizer、索引空间及数据迁移。
- 翻译正文为纯文本分段结果，保留段落和原文链接，不保证复刻邮件 HTML 排版。没有密钥时只能验证接口格式与错误处理，不能验证线上额度或服务可达性。
- 提醒与延迟发送受 Android 后台调度约束，10 秒表示最早提交时间，不保证精确到秒；关闭通知会延后提醒尝试。参考 [Android WorkManager 工作请求说明](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)。
- 邮件正文缓存统计内容字节，不等于 SQLite 数据库磁盘占用；删除缓存不会立即压缩数据库文件。下载的附件由系统文件管理器管理。
- 通知分级适用于本地同步出的具体邮件；不带账号/发件人信息的通用云端提示无法按发件人过滤。
- Room 11→12 使用增加列迁移，保留现有邮件与账号。新增模块独立于核心 IMAP 同步与复杂邮件布局算法；未进行无关的大规模重写。

## 验证

- JVM：正文提取、分段、签名输入、参数化搜索、跨账号/缺失父邮件/循环回复关系、引用折叠。
- Android：Room 撤销截止时间与单次领取、缓存清理保护草稿/待发数据、中文与组合筛选、加密译文缓存隔离、通知规则、邮箱工具 UI 冒烟测试。
- 不使用测试向真实收件人发信，也不使用用户密钥触发付费翻译。真实收发、服务商限额和长时间省电待机提醒仍需有效账号实测。
