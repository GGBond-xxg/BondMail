# BondMail v1.5.9.5

- 补齐邮箱工具、正文翻译与发送撤销提示的 Liquid Glass 浮动容器样式，统一筛选和操作按钮。
- 邮箱工具的分类、账号、日期和通知筛选增加间距；提醒及日期按钮支持空间不足时换行。
- 新增/编辑联系人头像快捷选项增加横纵间距并自动换行；账号排序的上下移动按钮增加间隔。
- 回复技能的导入与保存、搜索加载更多、权限授权入口跟随当前主题。
- 设置 → 关于 → 开源声明新增 Liquid Glass / AndroidLiquidGlass / Backdrop 1.0.6 的来源、原作者版权、固定版本和本地改动说明，并补列 MIUIX 与 theSVG。
- APK 内打包完整上游 Apache 2.0 许可（含担保免责与责任限制）、BondMail MIT 许可及第三方声明，均可离线阅读。明确 BondMail 自身 MIT 许可不替代第三方许可。

本版继续保留邮件 WebView 兼容处理。设备验证仅使用 vivo，小米由用户手动测试。

验证：vivo 检查邮箱工具分类/账号/日期/通知筛选、联系人头像选项、回复技能导入和说明、Glass 调节与开源页面；浅深色二级页面间距与离线许可实机测试通过。优化构建和发布 lint 通过，APK 内许可证与仓库原文逐字一致。
