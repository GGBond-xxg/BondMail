# BondMail v1.6.0.1

- 桌面长按应用图标新增「写邮件」「添加邮箱」「刷新邮件」三个快捷入口。
- 写邮件优先使用当前或最近选择的有效账号；无账号时进入添加邮箱。已有编辑中的邮件会保留，不被快捷操作覆盖。
- 刷新复用首页同步流程；当前选择「所有邮箱」时同步全部已启用账号。
- 为 2×2、4×2、4×4 小组件补齐独立预览图片和预览布局，兼容使用图片预览的桌面，避免只显示应用图标。
- 预览使用公开示意内容，支持简体中文、繁体中文、英文，不包含真实账号和邮件。

已在 vivo Android 15 验证长按菜单、入口跳转和小组件缩略图。小米由用户手动验证，菜单外观与顺序由桌面控制。
