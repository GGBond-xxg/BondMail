# BondMail v0.2.16.1

## 动画

- 主界面写信按钮改为 Bottom Sheet 方向：写信页从底部进入并向底部退出，主页面保持静止，移除易闪烁的 FAB `sharedBounds`。
- 首页顶部标题栏和底部 Dock 改为常驻组件，通过 `graphicsLayer.translationY` 滑出屏幕，不再使用会改变布局高度的 `AnimatedVisibility`。
- 邮件详情顶部栏与底部操作 Dock 同样改为常驻位移，WebView 尺寸在滚动过程中保持不变。
- 首页滚动累计超过 52px、邮件正文累计超过 56px 后才切换 Chrome；方向反转会清空累计量，修复上下轻微抖动造成反复闪烁。
- 搜索入口改为容器插值动画：从右上搜索按钮位置扩展到完整搜索框，同时插值位置、尺寸、圆角、阴影和内容透明度。键盘在过渡结束后再请求焦点。

## 交互

- 邮件列表增加手势方向锁：垂直位移先超过触摸阈值时，本次手势禁止左右操作；惯性滚动停止 140ms 后才重新启用 SwipeToDismiss。
- 左右操作触发距离提高到列表宽度的 42%，减少斜向下滑误触。
- 顶部收件箱/星标/已发送等 Chip 的图标和文字改为整体水平居中。

## 邮件正文

- WebView 正文顶端加入可滚动的 92px 安全空间，让覆盖式顶部栏初始不遮挡发件人区域；顶部栏收回后该空间会随正文自然滚出。
- HTML 布局缓存版本升级到 `layout-v8`。
