# BondMail v1.1.1

## 未读样式修复

- 点击未读邮件时继续在本地乐观标记为已读，不等待 IMAP `\Seen` 提交完成。
- 邮件卡片底色与左侧蓝条、时间圆点和文字字重在点击当帧一起切换为已读样式。
- 移除卡片底色的延迟颜色动画，避免详情页背景快照冻结未读蓝色的中间帧。
- 返回邮件列表时不再出现蓝色底色延迟消失的问题。

## 版本与兼容性

- `versionCode = 111`
- `versionName = 1.1.1`
- 没有数据库结构变化，覆盖安装会保留账户、邮件、正文缓存、OAuth 授权和设置。

## 发布验证

- `testDebugUnitTest`、`lintPerformance` 与 `assemblePerformance` 执行成功。
- R8、资源压缩、APK v2 签名和 `1.1.1 (111)` 版本元数据检查通过。
- 真机验证未读底色从 `#0B1729` 立即切换为已读底色 `#090E17`，快速返回帧与 1.5 秒后的稳定帧颜色一致。
- 最终 APK 已在真实 Android 设备上覆盖安装，账户与邮件数据保留，启动未记录到致命异常。
