# BondMail v1.6.1

- Liquid Glass 底部导航改为纯图标，与 MIUIX、Material 3 保持一致；保留无障碍名称和选中状态。
- 开源声明内的完整许可、免责条款及第三方版权文档补齐通用右侧滑入动画，与“关于”其他页面一致；保留可预测返回和原列表滚动位置。
- 设置中“同步”分类更名为“工具”；新增验证码识别规则，支持字面模板、4–12 位长度、数字/英文字母类型、编辑、启停与删除，附可填入的示例及仅在本机运行的测试。自定义规则持久保存，并统一用于详情和通知。
- 新增本地验证码识别，检查邮件标题、文本正文和 HTML 正文；支持常见中英文、繁体中文以及日、韩、法、德、西、葡、意、印尼、俄、阿拉伯、泰和印地语提示词，兼容本地数字字符以及数字字母混合验证码。不会仅凭一个普通数字显示按钮，遇到相互冲突的验证码时不猜测。
- 识别成功后，邮件通知增加“复制验证码”操作，邮件详情在翻译按钮下方显示对应主题的复制按钮。翻译在上、复制在下，加载图片操作与翻译同排，保持间距。
- 邮件详情中的复制按钮一直保留，支持重复复制；从通知点击复制后，将该邮件标为已读并清除对应通知，行为与阅读邮件一致，不单独记录按钮使用状态。
- 通知先正常显示，再读取未缓存的正文来补充验证码操作；后台读取不会标记已读，更新按钮不会重复提醒。验证码标记为敏感剪贴板内容，不额外保存明文副本。

验证码识别使用本地规则，图片中的验证码和不能可靠判断的格式不会显示快捷复制；仍可使用邮件原有的文本选择复制。

验证：识别单元测试覆盖标题、正文、HTML、前导零、全角数字、分组数字、金额/地址/订单号及冲突验证码；vivo Android 15 检查三主题浅色/深色布局、后台通知复制并标记已读、对应通知清除、页面重复复制及已读状态持久化，并验证自定义规则的示例测试、保存、编辑、删除、重启恢复以及许可文档的进入和可预测返回。
