# BondMail v0.2.29.0

## 邮件详情首帧稳定

- 移除正文 WebView 与 Compose 加载占位层的整页交叉淡化。两层都包含相同的主题和发件人文字，透明度重叠时会短暂显得更粗，随后恢复正常字重；现在等待 Chromium 完成可见提交后一次切换，不再发生“粗 → 细”闪烁。
- 加载占位与最终页面使用相同的 Gmail 卡片几何：主题在页面背景上，发件人和正文位于同一张内容卡中。
- 继续保留正文加载进度、失败提示、重试、短邮件滚动和 WebView 渲染进程恢复。

## Gmail 风格内容区域

- 顶部栏、页面背景继续使用同一 Monet Surface，返回、星标、更多按钮及底部操作 Dock 均不变。
- 邮件主题继续在内容区顶部完整多行显示。
- 发件人信息和原始邮件正文合并到一张 24dp 圆角内容卡中，增加轻量边框与阴影，使正文从页面背景中清晰突出。
- 发件人名称右侧增加邮件时间；名称过长时单行省略，时间保持可见。
- FLUID 普通邮件与 DESKTOP_SCALED Newsletter 共用同一外层内容卡，Cloudflare、GitHub、网易与 Bybit 的既有宽度处理不按品牌改变。
- HTML 准备缓存升级为 `layout-v23`，不会继续复用旧版详情结构。

## 账户显示名称

- 邮件详情顶部栏显示当前邮件所属账户的显示名称，填补返回按钮与右侧操作之间的空白。
- 账户显示名称最大长度统一为 12 个字符。
- 添加账户、编辑账户、OAuth 新账户和授权码账户都使用同一长度上限。
- 应用启动时自动将旧版本中超过 12 个字符的本地显示名称截短，不删除账户或邮件数据。
