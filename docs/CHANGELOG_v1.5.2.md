# BondMail v1.5.2

## 设置与图标

- 同步设置按“同步频率 → CF 推送 → 工具 → 翻译”排列。
- 修复添加邮箱时 QQ Mail、Gmail、Yahoo 的图标显示。
- 增加本地图标优先、theSVG 离线补充和域名别名映射，以及可重复执行的图标同步脚本。

## 邮件正文翻译

- 支持阿里云、网易有道、Google、Microsoft，用户分别配置自己的密钥。
- 增加固定短句连接测试、加密译文缓存、目标语言选择和原文对照。
- 译文可在正文区域查看，保留原邮件链接；原邮件和回复内容不被修改。

## 邮箱效率功能

- 10 秒撤销发送，撤销后恢复为草稿；各页面均可看到撤销提示。
- 搜索支持发件人、日期、附件筛选及分批加载。
- 新增同步诊断、账号签名、回复模板、重要/静音发件人通知规则。
- 新增附件中心、按回复标识聚合的会话列表、引用历史折叠、稍后提醒。
- 增加正文、译文和网页资源缓存分类清理；保留账号、草稿和用户下载的附件。

## 更新与验证

- versionName：1.5.2；versionCode：146；Room 数据库迁移至 v12，保留旧数据。
- APK 与 v1.5.1.1 使用相同签名，可直接覆盖安装。
- 单元测试、Room 迁移和核心真机数据检查已通过。部分界面回归受到测试设备系统安全弹窗遮挡，未全部完成。
- 搜索与会话基于已同步到本地的邮件；提醒受 Android 后台调度影响。真实翻译、邮件收发需要有效账号和服务凭据。

详细入口与使用范围见 [邮箱效率功能](PRODUCTIVITY.md) 和 [翻译设置](TRANSLATION.md)。
