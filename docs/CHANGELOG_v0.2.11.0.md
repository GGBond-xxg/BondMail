# BondMail v0.2.11.0

本版集中修复邮件正文兼容性、启动闪烁、IMAP 速度和邮件详情页布局。

## 正文显示

- MIME 解析器升级到版本 6：递归处理嵌套 multipart、message/rfc822、HTML/XHTML、多个 alternative 正文和常见异常字符集。
- 不再简单选择遇到的第一段 HTML；会从多个 HTML 候选中选择信息更完整的一段。
- 增强 `cid:`、Content-ID、Content-Location、文件名、srcset 和 style 内嵌图片替换。
- 缓存中由旧解析器生成的正文会自动重新下载并解析一次。
- 空字符串 HTML 不再被误判为有效缓存，避免邮件永久显示空白。
- GitHub、Apple、Bybit 等表格邮件保留原始内部宽度，不再把所有嵌套表格强制改成 100%。

## 页面与交互

- 发件人信息并入正文 WebView，随邮件内容一起滚动。
- HTML 与纯文本统一走同一正文容器，页面左右保留 16dp 视觉边距。
- “本次加载图片”改成正文内紧凑的“显示远程图片”胶囊按钮。
- 底部改为浮动操作栏：回复、转发、分享位于一个胶囊中，删除为独立红色图标按钮。
- 关闭 `loadWithOverviewMode`，减少正文被整体缩小和字体比例异常。

## 速度与稳定性

- 启动时先从 Room 读取本地快照，再安装 Compose 内容，避免先显示空列表再闪出缓存邮件。
- 同步新邮件改为批量去重、批量写入和单次 Room 事务，移除逐条 12ms 延时。
- 多邮箱同步最多并行 3 个账号。
- 网络可用等待从每次最多 2.8 秒缩短为最多 600ms，并兼容 VPN 下 validated=false 的可用网络。
- 复杂正文改为完整 MIME 下载，避免大量 64KiB 分段请求。
- 同一邮箱短时间复用已认证 IMAP Store，减少反复 TLS 建连和登录。
- 获取正文和标记已读合并到同一 IMAP 会话。
- 新增连接、文件夹打开、MIME 获取、解析和总耗时日志。

## 刷新率

- 启动与恢复前台时请求当前分辨率支持的最高刷新模式。
- 同时设置窗口首选刷新率和当前分辨率下的最高显示模式。
- 新增 `BondMail-Perf` 日志，用于查看系统支持和 App 请求的刷新率。
