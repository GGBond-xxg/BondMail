# BondMail v1.6.0.2

- 「查看完整许可与免责条款」和「查看第三方版权与改动说明」接入通用可预测返回动画。
- 侧滑返回时详情页跟随手势移动，取消手势后恢复；顶部返回按钮也使用同一套动画。
- 返回开源声明列表时保留滚动位置，避免回到列表顶部。
- 沿用系统减少动画设置，许可与版权正文不变。
- 关于页顶部改用当前主题的卡片，紧凑排列应用图标、名称、版本及简介。
- Glass 的普通按钮、图标按钮、下拉、筛选按钮、输入框、菜单和底栏统一细边框，浅色和深色均可辨认；禁用状态使用较淡边界，不增加阴影。
- 关闭玻璃特效时继续使用同一套边框规则；输入错误状态保留错误色。
- 设置下拉的文字箭头改为矢量图标，展开和收起分别显示上、下箭头。

验证：vivo Android 15 真机检查浅色/深色、玻璃特效开启/关闭、按钮禁用及输入错误状态；检查三个主题的关于页，复测服务表单间距和许可详情的返回进度、取消恢复、列表滚动位置。未操作小米，具体设备效果仍以实机为准。
