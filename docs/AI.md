# AI 邮件助手

从 v1.5.4 起，设置 → 同步 → AI 服务可以配置以下两种接口，密钥分别加密保存在本机：

| 类型 | 地址与模型 |
| --- | --- |
| 兼容 OpenAI | 填写服务商提供的 HTTPS API 基础地址和模型 ID；应用追加 `/chat/completions`，也接受完整的该端点地址。可用于提供这一协议的 DeepSeek 等服务。 |
| Gemini API | 使用 Google 官方 `generateContent` 端点；填写 API Key 和该账户可用的模型 ID。 |

基础地址必须包含服务商要求的路径，例如 `/v1`；不要填写网页聊天地址。模型 ID 使用服务商控制台显示的 API 名称。不同服务商对模型、地区与额度的限制不同，兼容协议不代表每个模型都已实测。

保存配置不会联网；“测试连接”只发送固定文字 `Hello`，可能消耗服务额度。应用不内置公共密钥，也不承诺免费额度。Google 账号登录与 Gemini API Key 是不同的接入方式，本版不提供通过网页登录使用 AI 的功能。中国大陆用户可以配置当地可访问的兼容服务。

## 在邮件里使用

打开一封已加载正文的邮件 → 右上角更多 → AI 邮件助手。

- **摘要**：概括邮件目的与主要信息。
- **重点 / 待办**：提取行动事项及邮件中明确给出的期限、负责人，不自动建立提醒。
- **生成回复**：可先输入语气、语言或想表达的内容；生成后点击“带入回复编辑页”，检查收件人和正文，再手动发送。
- **提问**：围绕当前邮件连续问答；后续问题包含本页已有对话。摘要、待办或重新生成回复会开始新的上下文。

回答可以选择复制。AI 不能读取其他邮件、打开链接、修改账户、创建日程或自动发送邮件。缺失事实仍需自行核对，生成内容不能代替原始邮件。

## 数据与限制

每次主动操作将**原始邮件标题、正文文字、你的要求**发送给界面显示的服务；连续问答还包含本轮对话。不会把译文替换成原文上下文，也不上传图片和附件。隐藏 HTML、脚本和样式不作为正文。外部邮件文字按引用资料处理，接口不注册工具或执行能力。

对话仅驻留内存，关闭助手即清空；选择带入的回复进入现有写信流程。服务商如何保留数据、使用配额和计费取决于其政策。应用错误提示不展示服务返回的原始错误正文或密钥。

- 邮件标题与正文合计最多 40,000 字符，超出会提示，**不会悄悄截断发送**。
- 每轮最多 10 次请求，对话历史另限 40,000 字符；达到上限后可清空继续。
- 输入框最多 2,000 字符，生成回复时加上任务说明也受请求长度限制。
- 可取消请求；离开页面会取消正在等待的请求。服务端已开始的处理仍可能计费。
- 不接受重定向，不自动重试，连接与响应均设超时。

接口实现依据：[OpenAI Chat Completions 官方参考](https://developers.openai.com/api/reference/resources/chat)、[Gemini generateContent 官方参考](https://ai.google.dev/api/generate-content)。

本地验证使用虚构邮件和模拟返回，不调用用户密钥。真实服务的权限、网络可达性和收费额度需用自己的配置测试。
