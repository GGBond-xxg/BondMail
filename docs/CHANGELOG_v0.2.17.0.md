# BondMail v0.2.17.0

本版完成 v0.2.16.1 之后的首页、写信、邮箱管理、删除确认、邮件手势和性能包体积优化。业务重点是让所有“写邮件”入口使用同一个底部抽屉，同时把邮箱账户管理集中到首页抽屉。

## 1. 性能构建和包体积

- `performance` 构建启用 `isMinifyEnabled = true`。
- 启用 `isShrinkResources = true`。
- 使用 `proguard-android-optimize.txt`。
- 增加 WorkManager、Room、JavaMail、Activation 和 WebView 回调保留规则。
- 继续保留 Debug 包的完整日志和调试能力；动画与滚动最终应使用 performance 包判断。
- 移除当前不再使用的 `SharedTransitionLayout` 和共享元素 Key 层，减少首轮组合与共享转场开销。

性能包首次构建会执行完整 R8，构建耗时会增加。实际 APK 和安装体积必须以本机 `assemblePerformance` 结果为准。

## 2. 底部导航和独立操作按钮

- 选中指示器由图标附近的小圆底改为覆盖整个导航项目的 `48dp` 椭圆。
- 选中椭圆、点击范围和涟漪使用同一圆角边界。
- 指示器保留低强度阴影和弹簧位移，但不使用明显过冲。
- 右侧写信按钮整颗使用 `primary/onPrimary`，不再出现按钮里又套一层图形的视觉。
- 邮件详情删除按钮整颗使用错误强调色容器，和普通回复/转发操作明确区分。

## 3. 删除确认

- 邮件详情点击删除后显示“是否删除该邮件”确认对话框。
- 首页批量删除会显示选中邮件数量。
- 邮箱账户删除在抽屉中显示独立确认提示。
- 取消对话框不会更改本地或服务器状态。

## 4. 首页邮件左右手势

- 从左向右滑动：已读邮件变未读，未读邮件变已读。
- 从右向左滑动：未星标邮件加星标，已星标邮件取消星标。
- 触发阈值提高到卡片宽度的 50%。
- 纵向位移优先；方向不明确的斜向手势按纵向滚动处理。
- LazyColumn 正在拖动或惯性滚动时禁用横向邮件操作。
- 列表停止后保留短暂 idle gate，避免同一次滑动尾部被重新解释为左右手势。

## 5. 写邮件改为 80% 底部抽屉

- 写信不再作为普通全屏导航路由出现。
- 首次打开显示约屏幕高度的 80%。
- 向上拖动可以展开为全屏。
- 在部分展开状态向下拖动会关闭抽屉。
- 全屏状态按返回键先退回 80%，再次返回才关闭。
- 首页写信按钮、联系人邮箱地址、详情回复和详情转发都复用同一个全局 `ComposeScreen`。
- 来源页面保持在抽屉下方，不执行额外整屏淡出或缩放。
- 发件账户、域名建议和附件区域改用低对比容器色，避免与首页风格割裂。

## 6. 附件选择和后台发送

- 使用 `OpenMultipleDocuments` 支持系统文件选择器多选。
- 单封邮件最多保留 10 个附件。
- 附件以 Chip 显示，可在发送前单独移除。
- 保存 Android 持久化读取权限，确保进入发件箱后 App 关闭仍可读取附件。
- `OutboxEntity` 新增 `attachmentsJson`。
- Room 数据库升级为 v5，并加入 4→5 迁移。
- SMTP 在存在附件时发送 `multipart/mixed`：第一个部分为 UTF-8 纯文本正文，后续部分为附件。
- 附件名称从 `OpenableColumns.DISPLAY_NAME` 读取，MIME 类型由 `ContentResolver` 获取。

## 7. 搜索容器动画

- 搜索按钮记录真实 `boundsInRoot`，容器从该位置扩展。
- 原搜索按钮在打开和关闭过渡期间保持隐藏，避免原图标与动画图标重复绘制。
- X/Y、宽度、高度、圆角、遮罩和输入内容 alpha 由同一个 Transition 驱动。
- 容器完成展开后才请求输入焦点和弹出键盘。
- 关闭时动画图标收回源位置，过渡结束后原按钮才重新出现。

## 8. 首页顶部操作

- 搜索、更多和添加邮箱统一为 `44dp` 圆形按钮。
- 三个按钮使用相同背景、图标尺寸和间距。
- 原右上角“全”账户按钮改为添加邮箱入口。

## 9. 设置页和首页抽屉

设置页移除：

- 邮箱账户管理卡片。
- 添加邮箱按钮。
- 编辑邮箱按钮。
- 独立邮箱排序页面入口。

首页抽屉改为：

- 移除顶部“邮箱”标题块。
- “所有收件箱”改为“所有邮箱”。
- 移除“邮箱账户”分组文字。
- 默认显示前三个邮箱。
- 只有邮箱超过三个时才显示展开/收起按钮。
- 每个邮箱显示长按拖动手柄、邮箱名称/地址、编辑图标和删除图标。
- 长按手柄并拖动后，将顺序写入 `AccountEntity.sortOrder`。
- 邮箱顺序统一应用于首页抽屉、后台同步和写邮件账户选择。
- 邮箱重命名最长 32 个字符。
- 删除邮箱同时清理本地消息、文件夹、发件箱、通知去重记录和本机凭证；服务器邮件不受影响。

原 `AccountOrderScreen.kt` 已移除，不再维护第二套排序界面。

## 10. 多语言

新增或更新简体中文、繁体中文和英文文案：

- 所有邮箱。
- 附件添加/移除。
- 邮件删除确认和批量删除确认。
- 邮箱展开/收起。
- 长按拖动排序。
- 邮箱重命名与账户删除说明。

三份 JSON 保持完全相同的 Key 集合。

## 11. 验证状态

已执行：

- Kotlin PSI 语法解析：40 个 Kotlin 文件，0 个语法错误。
- 三份 i18n JSON 解析和 Key 集合一致性检查。
- `%s/%d` 占位符数量一致性检查。
- `tr("...")` 静态文案引用检查，无缺失 Key。
- Android XML 解析检查。
- 补丁应用和源目录逐文件一致性检查。
- ZIP 完整性和项目 SHA256 清单检查。

当前交付环境没有可用 Android SDK，也无法通过容器 DNS 下载 Gradle/Android 依赖，因此未在此环境执行 Android Gradle 类型解析、Room KSP、R8 或 APK 生成。用户本机首次构建应先执行 `compileDebugKotlin`，再执行 `assemblePerformance`。
