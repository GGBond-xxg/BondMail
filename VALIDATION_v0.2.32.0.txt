Implemented scope
-----------------
- Pull-to-refresh is disabled while long-press selection mode is active and any existing pull
  offset is settled back to zero.
- Selection actions are ordered Select all / Deselect all, Delete, Mark read / Mark unread.
- Home and Contacts expose the shared animated scroll-to-top circular action after the list moves
  away from the top; returning to the top hides it automatically.
- First presentation of a message uses a stable background and a 300 ms committed-document fade.
  A static skeleton is delayed 450 ms and contains no moving progress indicator. Previously
  presented documents attach without replaying the reveal.
- Interactive messages up to 8 MiB are materialized with one IMAP PEEK MESSAGE fetch before MIME
  parsing. Body operations use 45-second socket read/write timeouts.
- Failed/empty interactive MIME parsing receives a bounded raw RFC822 local reparse fallback up to
  20 MiB. Larger messages retain partial MIME access.

----------------

attempted to obtain Gradle from services.gradle.org, but outbound network resolution is unavailable
(UnknownHostException). Android compilation and APK assembly therefore were not claimed here.
Compile locally with:

  .\gradlew.bat --stop
  .\gradlew.bat clean compileDebugKotlin assembleDebug assemblePerformance --no-daemon
